# Terminal Portfolio - Yiqi Wang

A Linux terminal-style personal portfolio website showcasing my skills, projects, and experience.

## 🚀 Features

- **Interactive Terminal Interface**: Fully functional terminal simulation
- **Multiple Commands**: Various commands to explore my profile
- **Responsive Design**: Works on desktop and mobile devices
- **Command History**: Navigate through previous commands with arrow keys
- **Modern Styling**: Sleek terminal aesthetic with green-on-black theme

## 📋 Available Commands

| Command | Description |
|---------|-------------|
| `help` | Display all available commands |
| `me` | Show personal information and bio |
| `ls` | List all projects |
| `contact` | Display contact information |
| `skills` | Show technical skills and proficiency levels |
| `education` | Display educational background |
| `experience` | Show professional experience |
| `clear` | Clear the terminal screen |
| `whoami` | Display current user |
| `date` | Show current date and time |
| `pwd` | Show current directory |
| `echo [text]` | Display specified text |
| `cat [file]` | Display file contents |

## 🎯 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/kylinwang2018/kylinwang2018.github.io.git
   ```

2. **Open the project**:
   - Simply open `index.html` in your web browser
   - Or serve it using a local server for development

3. **Customize the content**:
   - Edit the personal information in `script.js`
   - Modify the styling in `style.css`
   - Update the structure in `index.html` if needed

## ✏️ Customization

### Personal Information
Update the following sections in `script.js`:

1. **About Section** (`showAbout()` function):
   - Personal summary
   - Current focus areas
   - Location and contact links

2. **Projects Section** (`showProjects()` function):
   - Add your actual projects
   - Update descriptions and technologies
   - Modify project status

3. **Contact Information** (`showContact()` function):
   - Replace placeholder email and social links
   - Add or remove contact methods

4. **Skills Section** (`showSkills()` function):
   - Update programming languages and proficiency
   - Modify technology stacks
   - Adjust skill levels

5. **Education & Experience**:
   - Replace placeholder information with actual details
   - Add more positions or educational background as needed

### Styling
Modify `style.css` to:
- Change color scheme
- Adjust terminal size and appearance
- Update responsive breakpoints
- Customize project item styling

## 🌐 Deployment

This project is designed for GitHub Pages deployment:

1. Push your changes to the `main` branch
2. Enable GitHub Pages in your repository settings
3. Your site will be available at `https://yourusername.github.io`
